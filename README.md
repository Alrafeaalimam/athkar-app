# athkar-app
حصن المسلم هو تطبيق مجاني للأذكار اليومية، تم تطويره بواسطة الرفيع الإمام (ALRAFEA) ليكون صدقة جارية عن الوالدة المربية الشريفة زبيدة الشيخ عوض الجيد، والأخ والصاحب الزهاوي يوسف مصطفى رحمهما الله. يضم أذكار الصباح والمساء، وأذكار الصلاة والنوم والسفر وغيرها، ويعمل دون الحاجة إلى اتصال بالإنترنت.
